# SQL-Practice-Solutions
This repository contains my complete sql database query challenges from [sql practice.com] [https://www.sql-practice.com/].

**#Project-overview**
The challenges are based on a medical/hospital database schema, focusing on data extraction, filtering and complex analytical tasks.

**#Key SQL concepts covered**
* Advance filtering & Joins - Connecting tables using 'INNER JOIN', 'LEFT JOIN', 'RIGHT JOIN' on specific criteria.
* Aggregate Functions & Grouping - Extracting summarized data using 'GROUP BY' performing mathrmatical functions like 'COUNT()', 'SUM()', 'MIN()', 'MAX()', 'AVG()', 'HAVING'.
  
**Conditional Logic**
Used 'CASE WHEN'  - Checks data conditions line-by-line and outputs a custom value when a condition is met.

**Data Cleaning**
Handling missing data with 'IS NULL' operator.

**Repository Structure**
`hospital-solutions.sql` : Complete list of solutions grouped by difficulty level.
